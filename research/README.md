# Исследования модели автопилота

Скрипты для проверки отбора игроков (`kontur/scout.py`). Запуск из корня репозитория, базы — вне git.

| Скрипт | Что делает |
|---|---|
| `sim_model.py` | Синтетический рынок с известной «правдой» об игроках (умелые, покупатели фаворитов без знания, шум…): отбор на дату T, результат после T. `PYTHONPATH=. python research/sim_model.py 20` |
| `crawl_all.py` | Загружает ставки всех профилированных кошельков в копию базы (8 потоков, код приложения). `PYTHONPATH=. python research/crawl_all.py data/audit.sqlite3` |
| `live_audit_all.py` | Разбор на живых данных: кто проходит отбор, тест «умение или удача» относительно цены входа, проверка на истории (честная и как в приложении), «держится ли форма», качество данных. `PYTHONPATH=. python research/live_audit_all.py data/audit.sqlite3` |

Итоги прогона 23.11.2026 (919 кошельков, 1,73 млн позиций):
- отбор проходят 5 из 919; из 83 игроков с подтверждённым умением (относительно цены, поправка BH 5%) отбор берёт 3, 77 отсеяны порогом «70% выигрышей»;
- доля выигрышей почти целиком задаётся ценой входа (корреляция 0,8);
- связь «до → после»: доля выигрышей 0,53, доходность 0,14;
- честная проверка на истории: состав −1,3% / +16,5% / +2,2% (30/60/90 дней), без лучшего игрока −2,4% / +5,1% / −2,0%;
- встроенная проверка на истории завышает базу (63% выигрышей против 48% у всех игроков);
- 6 744 позиции на закрытых рынках с ценой 0/1 не считаются решёнными; комиссия в оценке занижена (0,02 против 0,04–0,07).

## Сравнение трёх логик отбора (`compare_logics.py`)

`PYTHONPATH=. python research/compare_logics.py data/audit.sqlite3 out.json`

результат — копии ставок, открытых в следующие 30 дней; цена копии = цена игрока + проскальзывание + комиссия 0,05·p·(1−p);

## С 1.3.0: хранение ставок

Ставки кошельков лежат в `scout_packs` (одна сжатая запись на кошелёк, `kontur/packs.py`), а не в `scout_bets`.
Скрипты (`crawl_all.py`, `compare_logics.py`, `live_audit_all.py`) вызывают `store.init`: старая база переносится сама
и сверяется до последнего поля (исследовательская база: 1 285 → 285 МБ, 2,5 млн ставок совпали).
