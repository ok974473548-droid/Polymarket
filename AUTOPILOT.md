# Автопилот: автоматический подбор игроков для копирования

Цель: копии ставок выигрывают в среднем в 70–80% случаев и при этом приносят прибыль. Система опирается на людей: она ищет трейдеров, чьи ставки выгодно повторять, держит из них состав, проверяет новичков на скамейке и меняет отстающих без участия пользователя. Все суммы и цены — в долларах.

## 1. Как устроено

```
Поиск кандидатов ──► Оценка игрока ──► Скамейка (испытание) ──► Состав ──► Контроль ──► Замена
  рейтинги            история ставок     2 недели без денег       деньги      каждые        лучший со
  Polymarket          копируемость       по новым ставкам         общий        10 минут      скамейки
                      тип поведения                               бюджет
```

Кандидаты — прибыльные кошельки из топ-200 рейтингов Polymarket по всем категориям за неделю, месяц и всё время (несколько тысяч кошельков, обновление раз в 6 часов). Пул нужен широкий: на живых данных копии большинства прибыльных трейдеров выигрывают в 40–55% случаев, а 70% и выше набирают примерно 3% из них (выборка 68 кошельков с 40+ ставками, ноябрь 2026). Прибыль им часто приносят редкие крупные выигрыши на дешёвых исходах, а не высокая доля угаданных.

Поиск и оценка общие для всех пользователей приложения. Состав, скамейка, бюджет и настройки у каждого пользователя свои.

## 2. Ставка игрока

Ставка — одна позиция игрока (исход одного рынка). Источник — Data API v2, позиции со статусом CLOSED и OPEN.

| Состояние позиции | Цена выхода | Как учитывается |
|---|---|---|
| CLOSED (продана или погашена) | `avg_price + realized_pnl / total_size` | решена |
| OPEN, `redeemable=true` (рынок разрешён, не погашена) | `current_price` (0 или 1) | решена |
| OPEN, рынок идёт | `current_price` | открыта, оценивается по рынку |

Важно: проигравшие позиции почти никто не гасит, они остаются OPEN с ценой $0. Если считать только CLOSED, доля выигрышей завышается в разы. Поэтому разрешённые OPEN учитываются обязательно.

Не учитываются:
- ставки дешевле $5;
- вход ниже $0.02 (такие автопилот не копирует);
- позиции с нулевым результатом (слияние Да+Нет).

### Копия ставки

Автопилот повторяет сделку с задержкой, поэтому платит дороже игрока:

- вход копии = средняя цена игрока + проскальзывание игрока (медиана по его последним покупкам через 60 секунд после сделки, минимум $0.005);
- комиссия — как у настоящих копий: `0.05 × цена × (1 − цена)` на акцию при входе и при продаже до разрешения (до 1.10.0 оценка была 0.02 — в 2,5 раза меньше реальной);
- если копий игрока уже было больше пяти, проскальзывание берётся не меньше того, что реально заплатили его рыночные копии (живые копии тонких рынков стоили в 4 раза больше оценки «цена через 60 секунд»);
- доходность копии на $1 = `(выход − вход − комиссии) / (вход + комиссия)`;
- выигрыш — доходность больше +0,2%, проигрыш — меньше −0,2%.

Каждая копия считается одинаковой ставкой, потому что автопилот ставит фиксированную долю бюджета, а не сумму игрока.

## 3. Профиль игрока

Окно оценки — 180 дней по дате входа (настраивается).

| Показатель | Что значит |
|---|---|
| Доля выигрышей копий | выигрыши / (выигрыши + проигрыши) |
| Надёжная граница | нижняя граница 95% интервала Уилсона: сколько выигрышей доказано историей |
| Доходность на ставку | средняя доходность копии на $1 |
| Преимущество над ценой | средняя разница «выход − вход» в долларах на акцию |
| Средняя цена входа | для сравнения с долей выигрышей |
| Коэффициент прибыли | сумма выигрышей / сумма проигрышей |
| Просадка | максимальное падение суммы копий, в ставках |
| Доля лучшей ставки | какую часть прибыли дала одна ставка |
| Стабильность | доля месяцев (от 5 ставок) с долей выигрышей не ниже цели минус 10 п.п. |
| Свежая форма | доля выигрышей по последним 20 ставкам |
| Активность | новые ставки за 14 и 30 дней |
| Проскальзывание | медиана сдвига цены через 60 секунд после покупок игрока |
| Время удержания | медиана дней от входа до выхода |
| Превышение над ценой | насколько чаще копии выигрывают, чем обещала цена: выигрыш − цена копии, в среднем; сжато к нулю множителем n / (n + 40) по числу событий |
| Доходность сверх цены | средняя доходность копии по событиям, сжатая так же; это и есть ожидаемая доходность копии |
| Доказанность | t-статистика по событиям (ставки одного события считаются одной) и вероятность получить такое случайно (p) |

### Тип поведения

| Тип | Признак | Копировать |
|---|---|---|
| Направленный | ставит на одну сторону, держит или осмысленно выходит | да |
| Краткосрочные крипторынки | 40%+ ставок на рынках «Up or Down» на минуты и часы | нет: задержка съедает всё |
| Маркетмейкер | 25%+ рынков с позициями на обе стороны или 150+ сделок в день при 40%+ продаж | нет |
| Скупщик почти решённых | 50%+ входов дороже $0.95 | нет: нет запаса прибыли |
| Высокочастотный бот | 300+ сделок в день | нет |
| Скальпер | медианное удержание меньше дня и 60%+ продаж | нет: выходы не успеть повторить |
| Мало истории | меньше 45 дней или мало решённых ставок | нет |

## 4. Отбор

С 1.10.0 есть два способа отбора, выбирается в настройках.

### Умение против цены (по умолчанию)

Покупка за 85¢ выигрывает в 85% случаев и ничего не зарабатывает, поэтому доля выигрышей сама по себе умения не показывает (на живых данных она на 80% задаётся ценой входа). Игрок проходит, если выполнено всё:

| Условие | По умолчанию |
|---|---|
| Тип | направленный |
| История | от 20 решённых ставок и 15 разных событий |
| Умение доказано | p не больше порога Бенджамини — Хохберга по всем кандидатам сразу (допускается 10% ложных находок среди отобранных) |
| Доходность сверх цены | от 2% |
| Выигрывает чаще, чем обещала цена | больше 0 |
| Доля лучшей ставки | не больше 40% |
| Новых ставок за 14 дней | от 2 |
| Проскальзывание | не больше $0.03 |

Балл 0–100: доходность сверх цены 50 (12% → полный), доказанность 20 (t от 2 до 6), стабильность по месяцам 15, копируемость 15.

На истории (1 512 кошельков, 4 окна) такой отбор с покупкой «по цене игрока, если цена вернулась за минуту» дал +6,3% на копию, 95% интервал +2,9…+10,1% (research/README.md).

### Доля выигрышей (как до 1.10.0)

Игрок проходит отбор, если выполнено всё:

| Условие | По умолчанию |
|---|---|
| Тип | направленный |
| Решённых ставок | от 40 |
| Доля выигрышей копий | от 70% |
| Надёжная граница | от 60% |
| Доходность на ставку | от +3% |
| Преимущество над ценой | от $0.02 на акцию |
| Доля лучшей ставки | не больше 40% |
| Новых ставок за 14 дней | от 2 |
| Проскальзывание | не больше $0.03 |

### Балл 0–100

| Часть | Вес | Шкала |
|---|---|---|
| Надёжная граница | 40 | 55% → 0, 85% → полный |
| Доходность на ставку | 25 | 0% → 0, 25% → полный |
| Стабильность по месяцам | 15 | доля хороших месяцев |
| Копируемость | 10 | проскальзывание $0 → полный, $0.04 → 0 |
| Свежая форма | 10 | 50% → 0, 90% → полный |

## 5. Скамейка и испытание

Скамейка всегда пополняется лучшими прошедшими отбор игроками (по умолчанию 4 места). На скамейке игрок копируется «в тени»: деньги не тратятся, а все его новые ставки после начала испытания оцениваются так же, как копии.

Испытание пройдено, если:
- прошло не меньше 14 дней;
- за это время у игрока не меньше 5 новых ставок;
- среди решённых доля выигрышей не ниже цели минус 15 п.п.;
- общий результат теневых копий (решённые + открытые по рынку) не хуже −5%;
- игрок по-прежнему проходит отбор.

Испытание провалено (игрок уходит на 30 дней):
- 5+ решённых и доля выигрышей ниже цели минус 25 п.п.;
- или результат хуже −25%;
- или перестал проходить отбор;
- или за двойной срок испытания меньше 2 новых ставок.

Стартовый состав набирается сразу из прошедших отбор: пока состав ни разу не был заполнен, каждое свободное место занимает лучший найденный игрок без испытания. Иначе первые недели автопилот бы бездействовал, ведь подходящие игроки находятся постепенно. После первого заполнения все замены идут через скамейку. Если размер состава увеличить, новые места тоже набираются сразу (до 1.10.0 они ждали скамейку 1–2 недели).

Игрок, убранный со скамейки вручную, не возвращается не меньше 7 дней (или срок «Выбывший может вернуться через»). До 1.10.0 автопилот при следующей проверке ставил его обратно, и испытание начиналось заново.

## 6. Состав и деньги

- Один профиль копирования «Автопилот» с общим бюджетом. Пополняется переводом с основного счёта.
- Доля игрока = бюджет (свободные деньги + открытые ставки по рынку) / число игроков, чьи покупки копируются (с 1.13.0), но не больше двойной доли «бюджет / размер состава». Пока подходящих игроков меньше мест, деньги не простаивают: 25.11.2026 при 7 копируемых из 20 мест в ставках было 14% бюджета.
- Одна копия = 10% доли игрока. При бюджете $1 000 и 8 игроках это $12,50 на ставку.
- Открытые ставки игрока не больше его доли. В одном событии все игроки вместе — не больше 10% бюджета.
- Если сразу несколько игроков купили одно и то же, каждая копия учитывается за своим игроком, но общий лимит на событие общий.

Правило выигрыша (×1,5) и порог размера сделки ($5) проверяются у каждой ставки, а не у игрока (с 1.15.0): игрок может делать и мелкие ставки, и ставки на фаворитов — такие просто не копируются, на отбор они не влияют.

Как покупается копия (выбирается в настройках):
- **Лимитная по цене игрока** (по умолчанию). Заявка по цене игрока ждёт 2 минуты. Сразу после покупки игрока дешёвые предложения выкуплены, но часто возвращаются. Что исполнилось — копия; что нет — снимается («Цена не вернулась»). Если игрок продал раньше, ждущая покупка снимается. Пока заявка ждёт, её деньги учитываются в доле игрока и в лимите на событие. На истории: +6,3% на копию против +1,5% у покупки сразу, исполняется около 40% копий; долгое ожидание хуже (заявка на 30 минут: +2,3% — исполняется тогда, когда цена падает дальше).
- **Сразу по рынку**. Цена исполнения не хуже цены игрока больше чем на меньшее из двух: $0.03 и 3% цены (но цент допускается всегда). До 1.10.0 был только допуск в долларах: при допуске $0.20 копию покупки за 15¢ исполнило по 31¢, в среднем копии стоили на 6–11% дороже игрока.

Что копируется:
- покупки игрока от $5 по цене от $0.02;
- **только ставки с весомым выигрышем** (с 1.12.0): при выигрыше копия должна вернуть не меньше ×1,5 вложенного, с учётом комиссии. Это покупка не дороже $0.655 за акцию (×2 — до $0.488). Раньше покупались ставки до $0.97, и копия $6 по $0.92 при выигрыше возвращала $6,50, а при проигрыше теряла все $6. У рыночной копии потолок цены — меньшее из допуска и этой цены;
- рынки, которые разрешатся не позже чем через 60 дней;
- покупка, которую сервер увидел позже чем через 15 минут (например, после перезапуска), не копируется: цена могла уйти;
- продажи игрока повторяются пропорционально, только в пределах акций этого игрока, даже поздние. Доля продажи считается по позиции игрока до сделки: если Data API ещё не обновился, его позиция и есть «до продажи».

Ставки на решённых рынках закрываются по итогу ($1 или $0 за акцию, при отмене 50/50 — $0,50) в течение 10 минут после решения.

## 7. Контроль и замена

Проверка каждые 10 минут по фактическим копиям игрока.

| Правило | По умолчанию |
|---|---|
| Серия проигрышей подряд | 5 |
| Доля выигрышей по последним 20 копиям (от 10 решённых) | ниже 55% |
| Убыток копий игрока | больше 30% его доли |
| Нет новых ставок | 14 дней |
| Перестал проходить отбор (с запасом: 5 п.п. по выигрышам, половина требования по активности, вдвое мягче порог доказанности) — только если на скамейке есть кому занять место | при ежедневном пересчёте |
| Ротация: на скамейке готов игрок сильнее на 15+ баллов | слабейший с 21+ днём в составе, не чаще раза в день |

- Правила по копиям включаются после 5 решённых копий игрока.
- Не больше 3 замен в сутки.
- Закреплённого игрока автопилот не меняет, только предупреждает.
- **Только продажи** (с 1.13.0). Игрок с мягкой проблемой («не проходит отбор»), которого пока некем заменить, остаётся на месте, но его новые покупки не копируются; продажи повторяются. В карточке — отметка «Только продажи». До 1.13.0 его покупки копировались дальше: 25.11.2026 семь таких игроков дали −$35 за сутки, прошедшие отбор — −$2. Закреплённого это не касается.

При замене:
- копирование игрока переходит в режим «только выходы»: новые покупки не делаются, продажи игрока повторяются, пока его копии не закроются;
- место сразу занимает лучший готовый со скамейки. Если готовых нет — лучший, кто пробыл на скамейке от 7 дней (можно выключить);
- игрок уходит на 30 дней, потом снова может стать кандидатом;
- запись в журнал и уведомление.

## 8. Проверка на истории

Чтобы не «предсказывать прошлое», проверка идёт со сдвигом даты:
1. Берётся дата T = 60 дней назад.
2. Профили считаются только по ставкам, решённым до T.
3. По тем же правилам выбирается состав.
4. Считается результат его ставок, сделанных после T.
5. Для сравнения считается результат всех кандидатов без отбора.

Ограничение: кандидаты берутся из сегодняшних рейтингов, куда трейдеры попали в том числе благодаря успехам после T. Поэтому оценка завышена, и решающим остаётся испытание на виртуальных деньгах.

## 9. Ограничения

- Задержка: сделки лидеров приходят из живого потока Polymarket, копия ставится примерно через секунду (медиана на живых данных — 0,9–1,1 с). Если поток недоступен, работает запасной опрос Data API, который отстаёт на минуты.
- Комиссия в оценке игроков — та же формула, что у копий (0.05 × p × (1 − p)); у рынков с другой ставкой копии берут реальную.
- Позиции крупных кошельков читаются в пределах окна оценки (до 6 000 закрытых и 4 000 открытых).
- Отбор по прошлому не гарантирует прибыль: на истории лучший вариант (умение + вход по цене игрока) дал около +6% на копию.
