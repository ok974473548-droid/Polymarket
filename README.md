# Контур рынка · 1.4.2

Аналитика Polymarket и виртуальная торговля с копированием сделок. По набору функций повторяет [polymarketanalytics.com](https://polymarketanalytics.com/), оформление своё: тёмная палитра и шрифт Inter. Интерфейс на русском, названия тегов Polymarket не переводятся. Ключи кошелька не нужны: все сделки виртуальные, но идут по живым ценам и стаканам Polymarket с настоящими комиссиями.

## Android-приложение

Папка `android/` — приложение «Контур» для телефона: интерфейс сервера в WebView. По умолчанию открывает облачный сервер на Railway; адрес можно сменить (долгое нажатие на значок → «Сменить сервер», или экран «Сервер не отвечает»). Вход и данные — те же, что в браузере. Уведомления о копиях, заявках и заменах в автопилоте приходят в фоне примерно раз в 15 минут.

Сборка: Android SDK (platform 35, build-tools 35), JDK 17+, Gradle 8.14: `cd android && gradle assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`. Для подписанной сборки — `android/keystore.properties` (вне git) и `gradle assembleRelease`.

## Новое в 1.4.2

**Сделки и ставки — в долларах, подробности по нажатию.** Вкладки «Активность» в копировании и автопилоте и «Ставки» автопилота.

- **Активность.** Вместо «85,01 × $0,32» в строке: сколько игрок потратил или получил и сколько вложили или получили мы. Сторона и исход — одной меткой («Купил «Нет»»). Причина пропуска — коротко: «Долгий рынок», «Цена ушла», «Мелкая сделка», «Лимит на событие» и т. п.
- **Подробности раскрываются под строкой** (нажатие на строку или на стрелку): акции и цена у игрока и у нас, комиссия, наша цена против цены игрока и допуск, задержка копии и источник (живой поток или запасной опрос), полная причина пропуска с кнопкой «Изменить в настройках», ссылки на рынок, профиль и сделку в блокчейне. Раскрытые строки остаются раскрытыми, когда список обновляется сам.
- **Ставки автопилота:** «Вложено / Стоимость сейчас / Результат» (с процентом), статус «Выигрыш», «Проигрыш» или «Продана». В подробностях — средняя цена входа с комиссией, цена рынка, стоимость по рынку и **«Если продать сейчас»**: сколько принесла бы продажа по текущим заявкам покупателей за вычетом комиссии (запрашивается из стакана при раскрытии).
- **Телефон:** строки стали карточками — таблицу больше не нужно листать вбок.
- **Результат ставки учитывает частичные продажи.** Результат открытой копии = стоимость оставшихся акций по рынку + уже полученное от продаж − вложенное. Было: стоимость оставшихся акций − вложенное в них, поэтому деньги от частичной продажи пропадали из строки. Пример: купили 100 акций за $50, продали 50 за $40, остаток стоит $30 — было +$5, стало +$20. Так же исправлен «Результат копий» игрока в составе (он участвует в замене игрока по просадке): итог карточки теперь равен сумме его строк во вкладке «Ставки».
- Исправлено: метка «Купил» в таблицах была размером с кнопку покупки.

Скорость: чтение ставок игроков быстрее (все кошельки 1,22 → 1,05 с, самый крупный 46 → 35 мс); задержка копии прежняя — медиана 0,95 с, наша часть 0,14 с (стакан и условия рынка теперь запрашиваются параллельно в момент обнаружения сделки).

Как это сделано:

- **Сжатие потока сделок.** WebSocket-клиент договаривается с сервером о `permessage-deflate` и держит общий словарь между сообщениями. Фильтра «только сделки этих кошельков» у Polymarket нет (проверено), поэтому сжатие — главный способ.
- **Стаканы только там, где нужна глубина.** Позиции переоцениваются по серединам цен из `POST /midpoints` (совпадают с серединой стакана); живой стакан держится только для исходов с лимитными заявками и для тикета, который открыт у пользователя.
- **Лёгкие запросы к Gamma** (`include_markets=false`) там, где рынки не нужны.
- **Догрузка позиций.** Закрытые позиции не меняются, поэтому повторно читаются только позиции с событиями после прошлой синхронизации (параметр Data API `start`, с перекрытием в сутки на задержку индексации); открытые — целиком, как раньше; позиция, купленная снова, уходит из закрытых. Ограничения прежние (не больше N самых свежих закрытых), так что цифры совпадают с полной загрузкой.
- **Ставки игрока — одна сжатая запись на кошелёк** (по столбцам, zlib) вместо строки на каждую ставку с повторяющимися адресами, хэшами и названиями. Старая таблица переносится при первом запуске без потерь (тест «было → стало»), потом файл базы сжимается (`VACUUM`); на базе после часа работы перенос занял 11 секунд.
- **Журнал копий:** ключ сделки — 8-байтовый хэш вместо ~150 символов текста; название рынка, исход, событие и картинка — один раз на исход в справочнике `outcomes`. Старые записи показываются как раньше.
- **Учёт трафика:** в `/api/status` — байты по видам запросов (`routes`) и по потокам (`wire` — пришло по сети, `plain` — после распаковки).

Как это сделано (по-прежнему только стандартная библиотека Python, без сторонних пакетов):

- **Живой поток сделок Polymarket (RTDS, WebSocket).** Сделки отслеживаемых кошельков приходят примерно через секунду и сразу копируются. Сделки одного лидера идут строго по порядку. Опрос Data API остался запасным (раз в 2 минуты, а при обрыве потока — раз в 30 с); одна и та же сделка из потока и из Data API узнаётся по ключу (транзакция, исход, сторона, размер), так что двойных копий не бывает — проверено: 83 из 83 сделок совпали, 0 дублей на 406 копиях.
- **Продажи лидера при быстром копировании.** Позиция лидера в Data API может ещё не учитывать только что сделанную продажу; по времени последнего события позиции это распознаётся, и доля продажи считается верно.
- **Живые стаканы (CLOB WebSocket)** для открытых позиций, лимитных заявок и только что оценённых исходов: переоценка и исполнение заявок без запросов в сеть. Если поток оборвался, стаканы берутся по сети, как раньше. Повторное частичное исполнение одной заявки — не чаще раза в 20 с, как в 1.1.1: виртуальная заявка не забирает ликвидность из настоящего стакана, и частая проверка иначе засчитывала бы одну и ту же ликвидность много раз.
- **Постоянные соединения и сжатие** для всех запросов к Polymarket; условия рынка запоминаются на 20 с.
- **Локальный сервер:** HTTP/1.1 keep-alive, gzip, кэш файлов в памяти с ETag (повторный заход — ответ 304), события для интерфейса через `/api/stream` (SSE), пул соединений с базой.
- **База:** `synchronous=NORMAL` в режиме WAL (запись не ждёт сброса на диск; на SSD/HDD это главный выигрыш, в замере выше диск в памяти, поэтому разница не видна), больше кэш, индексы для частых запросов.
- **Задержка видна в интерфейсе:** во вкладке «Активность» копирования и автопилота — колонка «Задержка» и сводка; в `/api/status` — состояние потоков, задержка копий, статистика сети.
- Новые переменные: `KONTUR_STATS_THREADS` (4) и `KONTUR_STATS_GAP` (0.06 с) для статистики трейдеров.

Где ещё можно выиграть: 0,8 с из секунды — путь сделки от Polymarket до приложения (поток RTDS — самый быстрый публичный источник; блокчейн медленнее). Запуск приложения на сервере рядом с Polymarket сократит эту часть. Оценка игроков автопилота по-прежнему считает проскальзывание через 60 с после сделки лидера — теперь это слишком осторожно, но менять формулу отбора без отдельной проверки не стал.

Замер: `PYTHONPATH=. python research/bench_perf.py`.

## Новое в 1.1.0

**Автопилот копирования** (пункт «Автопилот» в шапке). Система сама ищет трейдеров Polymarket, чьи ставки выгодно повторять, держит из них состав и автоматически заменяет отстающих лучшими со скамейки. Цель отбора — 70–80% выигранных копий при положительной доходности. Подробное устройство — в [AUTOPILOT.md](AUTOPILOT.md).

- **Отбор по истории.** Для каждого кандидата считается, как часто выиграли бы ваши копии его ставок за 180 дней: с задержкой 60 секунд, проскальзыванием и комиссией. Учитываются проигрыши, которые Polymarket оставляет «открытыми» с ценой $0 (если их не учитывать, доля выигрышей завышается в разы). Надёжность оценивается нижней границей интервала Уилсона, а маркетмейкеры, боты, скупщики почти решённых рынков и игроки краткосрочных крипторынков отсеиваются.
- **Скамейка.** Новые игроки 14 дней проверяются без денег на своих свежих ставках.
- **Состав.** По умолчанию 8 игроков делят общий бюджет поровну; одна копия — 10% доли игрока, не больше 10% бюджета на одно событие.
- **Замена.** Серия из 5 проигрышей, меньше 55% выигрышей по последним 20 копиям, убыток больше 30% доли, 14 дней без ставок или провал отбора — игрок выводится, его открытые копии закрываются вместе с его продажами, место занимает лучший со скамейки. Можно закрепить игрока, заменить или исключить вручную.
- **Настройки.** Все пороги отбора, копирования, испытания и замены меняются в меню «Настройки».
- **Проверка на истории.** Что было бы, если бы автопилот выбрал состав 60 дней назад, и сравнение со всеми кандидатами без отбора.
- В профиле трейдера — оценка автопилота и кнопка «На скамейку».

Также: все цены акций показываются в долларах ($0,34 вместо 34¢), диапазон цен в копировании и лимитная цена в тикете задаются в долларах. На ширине 760–1100 px в шапке появилась кнопка меню.

## Запуск

**Windows.** Распакуйте архив и дважды щёлкните `START.cmd`. Скрипт запустит Python 3.11+ (или Docker Desktop, если Python нет) и откроет http://127.0.0.1:8787.

**Вручную.**

```
python app.py            # http://127.0.0.1:8787
python app.py --port 9000 --db D:\kontur\data.sqlite3
python app.py --no-worker   # без фоновых задач (копирование и сбор статистики не работают)
```

**Docker.** `docker compose up -d --build`. Данные лежат в томе `kontur-data`.

Нужен только Python 3.11+ без сторонних пакетов. Приложению нужен доступ в интернет к Polymarket (gamma-api, clob, data-api), DefiLlama, Google News и Bing News.

## Первый вход

При первом открытии появится форма создания аккаунта: логин (3–40 латинских букв, цифр и символов `_ . @ -`) и пароль от 8 символов. На основной счёт сразу зачисляется $1 000. Пароль хранится как PBKDF2-SHA256; после 10 неудачных попыток вход с адреса блокируется на 15 минут. Сменить пароль можно в меню аккаунта, другие сеансы при этом завершаются. База рассчитана на нескольких пользователей; сейчас регистрируется один.

Без входа доступны все публичные страницы: рынки, события, трейдеры, теги, поиск, API. Портфель, тикет, избранное, уведомления и копирование требуют входа.

## Что есть в приложении

**Главная.** Карусель из пяти событий с наибольшим открытым интересом: четыре исхода, график за месяц, правила. Объём Polymarket за сутки, число доступных рынков, популярные трейдеры. Переключатель «Рынки / Трейдеры» и сетка карточек рынков с кнопками «Да» и «Нет».

**Рынки.** Вкладки «Обзор», «Новые» и категории. Сортировка по открытому интересу, объёму за сутки, ликвидности или новизне. Кнопка «Загрузить ещё».

**Карточка события.** Это главный экран, сделан по образцу `/event/presidential-election-winner-2028`:

- Шапка: теги с «+N ещё / − Меньше», объём, дата окончания, открытый интерес, избранное, ссылка на Polymarket.
- **График.** Периоды 24Ч / 7Д / 1М / 3М / YTD / 1Г / Всё и свой диапазон дат. Легенда показывает четыре ведущих исхода, «+N ещё» добавляет остальные. Любую линию можно скрыть.
- **Исходы.** Фото, объём, вероятность и изменение за сутки, кнопки «Купить Да $0,34 / Купить Нет $0,67». «Показать все позиции (N)», отдельно завершённые рынки.
- Короткие правила разрешения и источник.
- **Крупные держатели.** Выбор исхода и стороны (Да/Нет): акции, средняя цена, стоимость, PnL.
- **Сделки.** Флажки «Покупки / Продажи», «Показать метки» (метки трейдеров и «Крупная сделка» от $10 000), мини-шкалы суммы, цены и количества, подгрузка.
- **Новости.** Google News и Bing News, обновляются раз в 5 минут.
- **Тикет.**
  - Выбор исхода, «Купить / Продать», рыночная или лимитная заявка, кнопки «Да» и «Нет» с ценой акции в долларах.
  - Покупка в долларах: +$1 / +$5 / +$10 / +$100 / «Макс.». Сводка показывает среднюю цену, комиссию и сумму к выигрышу.
  - Продажа в акциях: 25 / 50 / 75 % / «Макс.» и «Вы получите».
  - Лимитная заявка: цена с шагом тика, количество акций, срок действия.

**Трейдеры.**

- Карточки «Объём», «Рынки в движении» и «Инструменты».
- Вкладки «Лидерборд / Киты / Спорт / Крипто / Политика», выбор категории.
- Сортировка по любому столбцу в обе стороны.
- Панель «Фильтры»: метка и диапазоны PnL, стоимости, активных позиций, прибыли, убытков, числа позиций и Win rate.
- Поиск, «Только активные», «Показать метки», 10 / 25 / 50 / 100 строк на странице.
- Статистика топ-200 каждой вкладки собирается в фоне.

**Профиль трейдера.**

- Слева:
  - общий PnL и шкала прибыли/убытка;
  - кнопки «Копировать» и «Избранное»;
  - стоимость позиций, сумма прибыли и убытков, Win rate, активные и все позиции;
  - эффективность капитала за 30 дней и текущая серия;
  - ссылка на профиль Polymarket.
- Вкладки:
  - **График** — общий или реализованный PnL за 7Д…Всё, изменения за 2/7/14/30 дней;
  - **Позиции** — активные или закрытые, поиск, фильтр по событию, сортировка;
  - **Категории** — ранг и статистика по категориям;
  - **Сделки** — фильтр покупок и продаж.

**Копирование.**

- Профили со своим балансом: «Пополнить», «Перевести с основного», «Вывести».
- Баланс можно скрыть. Показатели: доступно, в позициях, нереализованный P&L. Переключатель «Пауза для всех копий».
- Вкладки:
  - **Копии** — изменить, пауза, удалить;
  - **Позиции**;
  - **Активность** — все / исполнено / пропущено / ошибка с причиной, задержка каждой копии;
  - **Настройки** — переименовать, вывести, удалить профиль.
- Мастер из трёх шагов:
  1. Трейдер: адрес или выбор из рейтинга, имя, профиль.
  2. Размер: фиксированная сумма от $1,1 или процент от сделки лидера.
  3. Правила: лимит на сделку, дневной лимит, диапазон цен, проскальзывание (1/2/5/10 %, точная цена или любое), уведомления.
- Как работает копирование:
  - сделки лидеров приходят из живого потока Polymarket и копируются примерно через секунду; если поток недоступен, работает запасной опрос (Data API отдаёт сделки с опозданием в несколько минут);
  - копируются только сделки, сделанные после запуска копии;
  - продажи лидера повторяются пропорционально.

**Портфель.**

- Стоимость счёта, изменение за сутки, доступные средства, прибыль/убыток.
- «Пополнить» и «Вывести»: баланс виртуальный, его можно менять.
- График стоимости за 1Д / 7Д / 1М / YTD / Всё.
- Вкладки:
  - **Позиции** — поиск, сортировка, продажа по рынку;
  - **Открытые заявки** — отмена;
  - **История** — движение средств и заявки.

**Остальное.**

- **Избранное**: трейдеры, рынки, теги.
- **Теги**: число событий, страница тега.
- **Поиск**: рынки, трейдеры, теги; адрес `0x…` сразу открывает профиль. Строка поиска в шапке открывается клавишей `/`.
- **Уведомления**: колокольчик и всплывающие сообщения о копиях и заявках.
- **API**: справочник локальных JSON-маршрутов с кнопкой «Попробовать».

## Как считаются сделки

- **Покупка по рынку** проходит по уровням стакана CLOB. Сумма в долларах уже включает комиссию, минимум $1.
- **Комиссия тейкера** берётся с рынка: `акции × ставка × (цена × (1 − цена))^показатель`. Рынки без комиссии торгуются бесплатно.
- **Лимитная заявка** сначала исполняется по встречным уровням. Остаток встаёт в стакан с резервом средств или акций. Если рынок дойдёт до вашей цены, заявка исполнится как мейкерская, без комиссии. Цена округляется до тика, проверяется минимальный размер рынка.
- **Позиции** переоцениваются по середине стакана каждую минуту. После разрешения рынка они погашаются по 0 или 1.

## Автопилот: что важно знать

- Поиск игроков запускается при первом открытии страницы «Автопилот». Он проверяет прибыльные кошельки из топ-200 всех рейтингов за неделю, месяц и всё время. Первые кандидаты появляются через несколько минут, полный проход — около часа.
- Игроков с 70%+ выигранных копий мало: на живых данных это около 3% прибыльных трейдеров из рейтингов (у большинства 40–55%). Поэтому состав может заполняться постепенно, по мере проверки кандидатов. Если мест долго не хватает, порог можно снизить в настройках. Профили обновляются раз в 3 дня, игроков из состава и со скамейки — каждые 6 часов.
- Состав пересматривается каждые 10 минут, сделки лидеров копируются из живого потока примерно через секунду.
- Пока состав ни разу не был заполнен, места занимают прошедшие отбор сразу по истории; после первого заполнения все новые игроки проходят скамейку. Если готовых нет, место может занять игрок, пробывший на скамейке 7 дней (выключается в настройках).
- Выключение останавливает новые копии; открытые ставки остаются в профиле «Автопилот».
- 70–80% — цель отбора, а не гарантия. Проверка на истории завышена: кандидаты берутся из сегодняшних рейтингов.

## Ограничения

- Яндекс Новости недоступны для автоматических запросов (возвращают страницу ошибки), поэтому новости берутся из Google News и Bing News.
- Историю стоимости позиций (Networth) Polymarket не отдаёт, поэтому на графике профиля есть только общий и реализованный PnL.
- Сбор статистики топ-200 по всем вкладкам занимает несколько часов после первого запуска. Пока строка считается, в таблице видно «считается». Профиль, открытый вручную, считается в первую очередь.
- У кошельков с огромным числом позиций учитывается не больше 10 000 открытых и 25 000 закрытых. Такие значения помечены «+».
- Число событий у тегов считается по 2 000 самых активных событий за сутки.
- Вкладки «Создатели» в поиске, баланса USDC, депозитов и выводов в профиле трейдера и рекламы нет.

## Структура

```
app.py                HTTP-сервер, маршруты, прокси картинок
kontur/polymarket.py  Gamma, CLOB, Data API, DefiLlama; кэш в SQLite
kontur/trading.py     виртуальный счёт, заявки, комиссии, погашение
kontur/copytrade.py   профили и правила копирования
kontur/traders.py     рейтинги, статистика кошельков, метки
kontur/scout.py       поиск и оценка игроков для автопилота
kontur/autopilot.py   состав, скамейка, замены, размер копий
kontur/news.py        Google News и Bing News
kontur/worker.py      фоновые задачи (быстрый и медленный потоки)
static/               интерфейс (ES-модули без сборки), Inter, Lightweight Charts
tests/                python -m unittest discover -s tests
```
