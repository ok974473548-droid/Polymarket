# Контур рынка — памятка для Claude

Аналитика Polymarket и виртуальная торговля с копированием сделок и автопилотом подбора игроков.
**Все сделки виртуальные** (по живым ценам и стаканам Polymarket, с настоящими комиссиями); ключи кошелька не нужны.
Пользователь пишет по-русски; интерфейс, README и итоги — на русском, простым языком.

## Запуск и проверка
- Только Python 3.11+, без сторонних пакетов: `python app.py` → http://127.0.0.1:8787 (`--db`, `--port`, `--no-worker`).
- Docker: `docker compose up -d --build` (том `kontur-data`).
- Тесты: `PYTHONPATH=.:tests python -m unittest tests.test_trading tests.test_autopilot tests.test_data tests.test_speed tests.test_views` (140 тестов, без сети).
- Замер скорости: `PYTHONPATH=. python research/bench_perf.py` (сеть, сервер, база, поток сделок).
- Переменные: `KONTUR_DB`, `HOST`, `PORT`, `KONTUR_SCOUT_THREADS` (6), `KONTUR_SCOUT_GAP` (0.06 с), `KONTUR_STATS_THREADS` (4), `KONTUR_STATS_GAP` (0.06 с).

## Карта
| Файл | Что делает |
|---|---|
| `app.py` | HTTP-сервер на stdlib (HTTP/1.1 keep-alive, TCP_NODELAY, gzip, статика из памяти с ETag/304, пул соединений с базой), маршруты `/api/*`, события `/api/stream` (SSE), прокси картинок |
| `kontur/net.py` | HTTPS-клиент: постоянные соединения по хосту, gzip, системный прокси, GET и POST JSON, учёт байтов по маршрутам (`ROUTES`) |
| `kontur/ws.py` | WebSocket-клиент на stdlib (TLS, прокси, буфер кадров при таймаутах, сжатие permessage-deflate) |
| `kontur/stream.py` | Живой поток сделок RTDS → копирование за ~1 с; исполнители по лидерам (порядок сделок сохраняется) |
| `kontur/books.py` | Живые стаканы (CLOB WS) — только для лимитных заявок и открытого тикета; `books.get` — из памяти, предзагруженный или по сети; позиции переоцениваются через `pm.midpoints` |
| `kontur/crypto.py` | Криптораунды «вверх или вниз»: живые цены Chainlink (RTDS `crypto_prices_chainlink`, по запросу), данные раунда (цель, история: идущий — последние минуты, завершённый — целиком; прошлые раунды; `live` — идущий сейчас) с polymarket.com/api; `/api/crypto-round`, живой канал страницы события `/api/live` (SSE: `price` из стаканов — `books.shown`, `crypto`) |
| `kontur/packs.py` | Ставки игроков: одна сжатая запись (zlib, по столбцам) на кошелёк в `scout_packs`; перенос старой `scout_bets` при запуске |
| `kontur/bus.py` | Шина событий внутри процесса (для SSE): `account` (движение денег), `prices` (счета с изменившейся ценой), `copy`, `fill`, `autopilot`, `notify`; страница перерисовывается без мигания — `quietDraw` в `static/js/app.js`, триггеры и таймеры — `layout.js` |
| `kontur/views.py` | Какой график у страницы события, как решает Polymarket: `round` (криптораунд), `asset` (цена монеты), `single` (одна линия), `match` (цвета команд, ничья серая), `multi` (negRisk, `seriesColor` → палитра), `none` (независимые вопросы — только список); проверка на 41 событии исследования — `tests/data/events_24nov2026.json.gz` |
| `kontur/polymarket.py` | Клиенты Gamma / Data API v2 / CLOB, темп запросов по хостам, пауза для всех при 429, кэш; событие с `teams`, `score`, `series`, `tweets`, `view`; история цен — CLOB с шагами периодов Polymarket (`history_params`: 1Ч–1Д минута, 1Н 5 мин, 1М 30 мин, ВСЕ 12 ч, молодой рынок — с создания) |
| `kontur/scout.py` | Поиск и оценка игроков для автопилота: ставки из позиций (догрузка: закрытые — только новые, `start`), копия с задержкой и комиссией, метрики, тип поведения, отбор, балл, проверка на истории |
| `kontur/autopilot.py` | Состав, скамейка, испытание, замены, копии автопилота, настройки |
| `kontur/copytrade.py`, `trading.py` | Копирование (`handle` — одна сделка, ключ `trade_key` общий для потока и Data API, без дублей); заявки, проход по стакану, комиссии, позиции |
| `kontur/worker.py` | Фоновые задачи (fast / slow), пулы потоков `JobPool`: поиск игроков (`ScoutPool`), статистика трейдеров (`WalletPool`) |
| `kontur/traders.py` | Рейтинги и статистика трейдеров; закрытые позиции догружаются и хранятся картой «хэш токена → итог» (`wallet_closed`) |
| `kontur/accounts.py` | Несколько человек: приглашения (одноразовые ссылки, в базе только хэш), регистрация по ним, список пользователей, блокировка (вход и копирование останавливаются), удаление со всеми данными; страница `/admin` и `/join` — `static/js/pages/admin.js` |
| `kontur/news.py`, `watchlist.py`, `notify.py`, `auth.py`, `db.py` | Новости, избранное, уведомления, вход, база SQLite (справочник исходов `outcomes` для журнала копий) |
| `static/` | Интерфейс (JS без сборки). Дизайн — токены в `:root` `static/css/app.css`: `--radius` 16, `--card` (градиент), `--surface-shadow`, `--well`, фирменная пара `--brand`/`--brand-2`/`--brand-grad` (синий → бирюзовый); контейнер `.wrap` до 1 880 px; высота графиков — `fitHeight` в `chart.js`; строки сделок и ставок (деньги, подробности под строкой, карточки на телефоне) — `trades.js`; живые графики событий — `livechart.js`, прокрутка цифр — `roll.js` |
| `research/` | Скрипты проверки модели автопилота и итоги прогона |
| `AUTOPILOT.md` | Устройство автопилота |

## Договорённости
- Polymarket Data API — только v2; он отдаёт сделки с опозданием в минуты, поэтому копирование идёт из потока RTDS, опрос — запасной.
- Без сторонних пакетов: сеть, WebSocket, сервер — на стандартной библиотеке.
- Вес данных: запрашивать только нужное (`include_markets=false`, `start`, пакетные запросы), сжимать (gzip, permessage-deflate, zlib), не хранить повторы; любое облегчение сверять с полным вариантом на живых данных.
- Всё «на момент now», без заглядывания в будущее; проверка на истории — только по данным на дату отбора.
- Расчёты не меняются молча: при смене формулы — тест «было → стало» и строка в README.
- Версия — `kontur/__init__.py` и заголовок README; история — разделы «Новое в …» в README.
- База пользователя обновляется без потерь (новые таблицы и поля добавляются при запуске).

## Известные недостатки отбора (см. `research/README.md`)
Отбор по доле выигрышей копий ≥ 70% выбирает покупателей дорогих исходов, а не умение; нет теста на удачу относительно цены;
комиссия в оценке занижена; ставки одного события считаются независимыми; решённые рынки с ценой 0/1 остаются «открытыми»;
встроенная проверка на истории заглядывает в будущее (тип, проскальзывание, выборка «перспективных» — на сегодня).
